# Feedback matrix

## Severity

| Severity | Description | Action |
| --- | --- | --- |
| Blocker | Prevents import, review or export | Fix before beta continues |
| Critical | Risk of wrong data or lost trust | High priority |
| Important | Affects frequent flow but has workaround | Plan during beta |
| Improvement | Improves clarity or efficiency | Group by theme |
| Future idea | Outside current MVP | Record without promising |

## Area

| Area | Classification question |
| --- | --- |
| Ingest | Does the file enter and get identified correctly? |
| Mapping | Are columns assigned clearly? |
| Normalization | Are ADIF fields consistent? |
| Deduplication | Do detected duplicates make sense? |
| Conflicts | Is the manual decision clear and reversible? |
| Export | Is the final `ADI` useful and reviewable? |
| Documentation | Does the operator know what to do? |
| Installation | Does the app start without excessive friction? |
| Language | Are ES/EN clear for the operator? |
