# Interview script

## Before use

- What logger or tools do you use today?
- Where do your logs get scattered?
- What formats do you normally export?
- What worries you before uploading to LoTW/eQSL/ClubLog?

## During the test

- Which part of the flow is clear?
- Where do you hesitate before moving on?
- Does the mapper give enough control?
- Does preview help catch errors?
- Are conflicts understandable?

## After export

- Would you review this `ADI` before uploading?
- What would make you trust it more?
- Which format or case was missing?
- Did you see any data you did not expect?

## Future payment without sales pressure

- If this matures, what value would it have for you?
- Would you prefer a local one-time app, donation, simple license or another model?
- What technical condition would be mandatory before paying or recommending?
