# Matriz de feedback

## Severidad

| Severidad | Descripcion | Accion |
| --- | --- | --- |
| Bloqueo | Impide importar, revisar o exportar | Corregir antes de seguir beta |
| Critico | Riesgo de datos incorrectos o perdida de confianza | Prioridad alta |
| Importante | Afecta flujo frecuente pero tiene workaround | Planificar en beta |
| Mejora | Aumenta claridad o eficiencia | Agrupar por tema |
| Idea futura | Fuera del MVP actual | Registrar sin prometer |

## Area

| Area | Pregunta de clasificacion |
| --- | --- |
| Ingesta | El archivo entra y se identifica correctamente? |
| Mapeo | Las columnas se asignan de forma comprensible? |
| Normalizacion | Los campos ADIF quedan consistentes? |
| Deduplicacion | Los duplicados detectados tienen sentido? |
| Conflictos | La decision manual es clara y reversible? |
| Exportacion | El `ADI` final es util y revisable? |
| Documentacion | El operador sabe que hacer? |
| Instalacion | La app arranca sin friccion excesiva? |
| Idioma | ES/EN son claros para el operador? |
