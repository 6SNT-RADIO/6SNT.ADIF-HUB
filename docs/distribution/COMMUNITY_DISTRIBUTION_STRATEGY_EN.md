# Community distribution strategy

## Principle

No dedicated website at first. GitHub acts as the technical source of truth: releases, changelog, issues and documentation. Communities are used to learn, validate and request feedback, not to push sales.

## Channels

- Ham radio forums.
- Reddit.
- QRZ.
- eHam.
- Facebook groups.
- Local clubs.
- POTA/SOTA communities.
- Contest communities.

## Rhythm

Post sparingly, with context and value. Alternate education, discovery, closed beta and demos. Do not copy the same text into every channel.

## Recommended CTA

Ask for technical feedback and sanitized test cases. Avoid commercial links or sales messages in the first interaction.
