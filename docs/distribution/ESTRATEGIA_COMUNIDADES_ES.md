# Estrategia de comunidades

## Principio

Sin web propia al inicio. GitHub funciona como fuente tecnica principal: releases, changelog, issues y documentacion. Las comunidades se usan para aprender, validar y pedir feedback, no para empujar ventas.

## Canales

- Foros de radioaficion.
- Reddit.
- QRZ.
- eHam.
- Grupos Facebook.
- Clubes locales.
- Comunidades POTA/SOTA.
- Comunidades de contest.

## Ritmo

Publicar poco, con contexto y valor. Alternar educacion, discovery, beta cerrada y demos. No copiar el mismo texto en todos los canales.

## CTA recomendado

Pedir feedback tecnico y casos de prueba saneados. Evitar enlaces comerciales o mensajes de venta en la primera interaccion.
