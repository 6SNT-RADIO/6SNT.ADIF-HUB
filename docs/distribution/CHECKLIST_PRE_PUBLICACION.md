# Checklist pre-publicacion

- Idioma correcto.
- Canal correcto.
- Tono no vendedor.
- Reglas de comunidad revisadas.
- Captura sin datos reales.
- Link correcto.
- Version correcta.
- Limitaciones declaradas.
- CTA claro.
- No hay promesa de subida automatica externa.
- No hay datos privados en texto, imagenes o archivos adjuntos.
