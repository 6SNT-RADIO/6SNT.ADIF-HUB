# Flujo de trabajo recomendado

## Objetivo

Limpiar y consolidar antes de subir a LoTW, eQSL, ClubLog, QRZ u otras plataformas.

## Procedimiento

1. Haz backup de tus logs originales.
2. Crea copias de trabajo.
3. Importa primero un subconjunto pequeno.
4. Revisa mapper y preview.
5. Normaliza y deduplica.
6. Resuelve conflictos manualmente si hay dudas.
7. Exporta `ADI`.
8. Abre el `ADI` en una herramienta de confianza o con un visor ADIF.
9. Sube a plataformas externas solo cuando estes conforme.

## Buenas practicas

- No mezcles pruebas con tu log maestro.
- No aceptes fusiones masivas sin mirar conflictos.
- Guarda evidencia de la version de la app usada para la exportacion.
- Si un formato falla, conserva el archivo de origen para reproducirlo con datos saneados.
