# I18N

## Alcance

La interfaz React usa un sistema local de internacionalizacion ES/EN sin dependencias externas. Los textos visibles de navegacion, estados, botones, mensajes vacios, errores, mapper, inferencias, conflictos, busqueda y exportacion viven en:

- `frontend/src/i18n/locales/es.json`
- `frontend/src/i18n/locales/en.json`

La capa de runtime esta en `frontend/src/i18n/index.tsx`.

## Uso en componentes

Los componentes leen traducciones con:

```tsx
const { t } = useI18n();
```

Las claves usan rutas por punto:

```tsx
t("dropZone.headline")
t("conflicts.openTotal", { open, total })
```

Si falta una clave en el idioma activo, el sistema intenta español y luego devuelve la clave original. Esto evita pantallas rotas durante una beta, pero las claves faltantes deben corregirse antes de release.

## Selector de idioma

`TopNav` muestra un selector `ES/EN`. El cambio ocurre sin recargar porque el idioma esta en React Context. La preferencia se guarda en:

```text
localStorage["6snt.adifhub.locale"]
```

Idioma inicial:

1. preferencia guardada;
2. idioma del navegador si empieza con `en`;
3. fallback a `es`.

El proveedor tambien sincroniza `document.documentElement.lang`.

## Tokens no traducidos

Se mantienen como tokens tecnicos los nombres de campos, formatos y plataformas estandar:

`ADIF`, `ADI`, `ADX`, `Cabrillo`, `CSV`, `TSV`, `XLSX`, `JSON`, `QSO`, `CALL`, `FREQ`, `MODE`, `BAND`, `QSO_DATE`, `TIME_ON`, `DXCC`, `CQZ`, `ITUZ`, `LoTW`, `eQSL`, `POTA`, `SOTA`.

## Backend

Los mensajes HTTP visibles se centralizan en `backend/app/messages.py`. Por ahora la API responde en español, porque el frontend aun no envia cabecera/parametro de idioma. La estructura ya contiene ES/EN para permitir una futura negociacion por `Accept-Language` o preferencia explicita.

## Validacion

Validaciones minimas tras tocar i18n:

```powershell
cd frontend
npm run build
```

```powershell
cd backend
.\.venv\Scripts\python -m pytest
.\.venv\Scripts\ruff check app tests
```

Prueba manual recomendada:

1. abrir la app;
2. cambiar `ES` a `EN` en la barra superior;
3. confirmar que navegacion, botones, estados vacios y paneles cambian sin recargar;
4. recargar y confirmar persistencia en `localStorage`.
