6SNT.ADIF-HUB

Área local de preparación para operadores que necesitan limpiar exportaciones dispersas antes de tocar el log maestro.

Importa ADI, ADX, Cabrillo, CSV, XLSX y JSON, normaliza registros hacia flujos ADIF, revisa duplicados y exporta un archivo consolidado para inspección manual.

v0.1.0-beta Windows Fuente pública Apache 2.0 Local-first
Descargar EXE Release Repositorio

Qué hace

  • Importa logs ADI, ADX, Cabrillo, CSV, TSV, XLSX y JSON.
  • Mapea columnas y normaliza registros hacia convenciones ADIF 3.1.7.
  • Detecta candidatos duplicados y muestra conflictos para revisión.
  • Exporta un archivo ADI consolidado para herramientas posteriores.

Límites de seguridad

  • Trabaja localmente en la máquina del operador.
  • No requiere login, sincronización cloud ni telemetría.
  • No controla radios, PTT, TUNE, TX, audio ni CW.
  • Durante la beta, trabaja con copias.

No es para

No es un logger diario, no es un servicio cloud y no reemplaza LoTW, eQSL, ClubLog, QRZ, Log4OM, N1MM ni tu log maestro de confianza.

Revisa cada ADIF exportado antes de subirlo a un servicio importante.

Flujo

Un camino controlado desde exportaciones dispersas hasta un archivo ADIF revisable.

01
ImportarCarga uno o más archivos desde formatos comunes de logs de radio.
02
MapearConecta columnas de origen con campos ADIF estándar cuando hace falta.
03
NormalizarEstandariza fechas, bandas, modos y campos compatibles.
04
DeduplicarEncuentra candidatos QSO duplicados con reglas contextuales.
05
ResolverElige el registro ganador o una estrategia por campo para conflictos.
06
ExportarCrea un ADI consolidado para revisión manual.
