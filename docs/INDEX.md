## Flujo recomendado para beta

1. Leer [Quick start](manual/en/QUICK_START.md) o [Guia rapida](manual/es/GUIA_RAPIDA.md).
2. Preparar prueba con [Plan de validacion beta](validation/es/PLAN_VALIDACION_BETA.md).
3. Registrar hallazgos con [Matriz de feedback](validation/es/MATRIZ_FEEDBACK.md).
4. Comunicar usando [Mensajes clave](marketing/MENSAJES_CLAVE.md) y [No decir](marketing/NO_DECIR.md).
5. Revisar [Checklist pre-publicacion](distribution/CHECKLIST_PRE_PUBLICACION.md) antes de publicar.
