# No decir

Evitar estas promesas:

- "La mejor app de radioaficion".
- "Resuelve todos los problemas de logs".
- "100% compatible con todos los formatos".
- "Automatico sin revisar".
- "Sube directo a todas las plataformas".
- "Reemplaza LoTW/eQSL/ClubLog/QRZ/Log4OM/N1MM".
- "No necesitas revisar el ADIF final".
- "Puede trabajar sobre tu unico log maestro sin backup".

## Forma correcta

Usar lenguaje verificable:

- "Ayuda a limpiar y consolidar".
- "Procesamiento local".
- "Soporta formatos comunes con limitaciones documentadas".
- "Mantiene control manual en conflictos".
- "Exporta ADIF para revision y uso posterior".
