# Prelaunch FAQ

## Is it a logger?

No. It is a log preparation tool.

## Does it replace LoTW/eQSL/ClubLog?

No. It helps prepare an ADIF before using those platforms.

## Does it upload data to the internet?

Not in the current design. Processing is local.

## Can I use my real log?

Only with backup. During beta, test first with copies and subsets.

## Which formats are supported?

`ADI`, `ADX`, `Cabrillo`, `CSV`, `TSV`, `XLSX` and `JSON`, with documented limitations.

## Is deduplication automatic?

It detects candidates and offers resolution, but the operator must review important conflicts.

## What about sensitive data?

Do not upload it to the repo or share it in screenshots. Use sanitized data for bug reports.
