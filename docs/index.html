6SNT.ADIF-HUB

Local-first staging area for radio operators who need to clean scattered log exports before touching the master log.

Import ADI, ADX, Cabrillo, CSV, XLSX and JSON, normalize records toward ADIF workflows, review duplicates and export a consolidated file for manual inspection.

v0.1.0-beta Windows Public source Apache 2.0 Local-first
Download EXE Release Repository

What it does

  • Imports ADI, ADX, Cabrillo, CSV, TSV, XLSX and JSON logs.
  • Maps columns and normalizes records toward ADIF 3.1.7 conventions.
  • Detects duplicate candidates and exposes conflicts for review.
  • Exports a consolidated ADI file for downstream tools.

Safety boundaries

  • Works locally on the operator machine.
  • Does not require login, cloud sync or telemetry.
  • Does not control radios, PTT, TUNE, TX, audio or CW.
  • Use copies while the app is in beta.

Not for

It is not a daily logger, not a cloud service and not a replacement for LoTW, eQSL, ClubLog, QRZ, Log4OM, N1MM or your trusted master log.

Review every exported ADIF before uploading it anywhere important.

Workflow

One controlled path from scattered exports to one reviewable ADIF file.

01
ImportLoad one or more files from common ham radio log formats.
02
MapConnect source columns to standard ADIF fields when needed.
03
NormalizeStandardize dates, bands, modes and compatible fields.
04
DeduplicateFind duplicate QSO candidates with contextual rules.
05
ResolveChoose the winning record or field strategy for conflicts.
06
ExportCreate a consolidated ADI file for manual review.
